# Aşırı Resmi Mazeret Üreticisi

## Proje Hakkında

Bu repository, modern iş hayatının en acil ihtiyacına cevap vermek amacıyla geliştirilmiştir: **Hiçbir şey yapmadan her şeyi açıklayabilmek.**

Aşırı Resmi Mazeret Üreticisi, herhangi bir görevi, işi veya sorumluluğu yerine getirmemek için son derece bürokratik, abartılı ve tamamen ciddi görünen mazeretler üretir. Çıktılar o kadar resmidir ki, neredeyse bir devlet dairesinden gelmiş gibi durur.

**Önemli Uyarı:** Bu araç sadece eğlence amaçlıdır. Gerçek hayatta kullanırsanız ve şirketiniz sizi kovarsa, sorumluluk tamamen size aittir. Biz sadece mazeret ürettik.

## Özellikler

- Herhangi bir görev için anında resmi mazeret üretir
- Tamamen rastgele ve her seferinde farklı çıktı verir
- Bürokratik dil kullanır (çünkü herkes bürokrasiyi sever)
- Hiçbir dış bağımlılığı yoktur (Python yeterli)
- %100 çalışır (test edildi, gerçekten)

## Kullanım

```bash
python mazeret_ureticisi.py "raporu teslim etmek"
```

veya

```bash
python mazeret_ureticisi.py "toplantıya katılmak"
```

Çıktı, o kadar resmi ve uzun olacaktır ki, kimse itiraz etmeye cesaret edemeyecektir.
